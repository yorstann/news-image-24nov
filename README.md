# The World Today — Tuesday 24 November 2026

A one-image entry for make.fun's "News Image 24 Nov" bounty. The program in `main.ts` draws a complete broadsheet of the day's world news — COP31's collapse in Antalya as the lead, Ukraine's strike at Benghazi, Trump's warning to Iran, NATO airspace violations, Nvidia, and the Indonesia trade deal — entirely in code (own rasterizer, bitmap font and PNG encoder) and writes it to `/output/entry.png`.
