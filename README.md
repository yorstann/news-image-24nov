# 24 November in One Image — COP31: Collapse

A one-image entry for make.fun's "News Image 24 Nov" bounty. The program in `main.ts` draws a dark poster of the day's world news — one giant headline (the COP31 talks collapse), three hard numbers (50 hours of overtime, 90+ nations rejecting the text, zero mentions of fossil fuels), a split-iceberg illustration, four one-line story tiles (Benghazi, Iran, NATO, Nvidia) and a ticker with the Indonesia trade deal — entirely in code (own rasterizer, bitmap typeface and PNG encoder) and writes it to `/output/entry.png`.
